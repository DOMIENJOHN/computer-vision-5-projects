# Gesture Recognition for Robot Control

## Overview
A planned computer vision project to recognise hand gestures and map them to robotic control commands.

## Status
Planned — implementation and evaluation have not yet been completed.

## Proposed Workflow
1. Capture hand images using a camera.
2. Detect and classify hand gestures.
3. Map recognised gestures to predefined robot commands.
4. Validate command mapping and add safety checks before hardware control.

## Limitations
This repository currently contains the project outline only. No trained model, implementation, or experimental results are provided.

## Technologies
Python, OpenCV, and a suitable hand-gesture classification model (to be selected).
