# Dataset Information

## Dataset
CIFAR-10

## Source
https://www.cs.toronto.edu/~kriz/cifar.html

## Description
CIFAR-10 contains 60,000 colour images across 10 classes:
airplane, automobile, bird, cat, deer, dog, frog, horse, ship, and truck.

The standard split contains 50,000 training images and 10,000 test images.

## Use in this project
Train an image classifier, evaluate its predictions on held-out test data,
and generate Grad-CAM visualisations to inspect image regions influencing
the predicted class.

## Limitations
CIFAR-10 images are small (32 x 32 pixels) and do not represent every
real-world object-recognition scenario.
