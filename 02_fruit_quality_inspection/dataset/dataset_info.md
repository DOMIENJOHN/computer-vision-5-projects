# Dataset Information

- **Dataset:** Fruit Classification Dataset
- **Source:** https://huggingface.co/datasets/menasi11/fruit-classification
- **Task:** Six-class image classification
- **Training images:** 1,058
- **Test images:** 453
- **Training labels:** `source/train.csv`
- **Test submission file:** `source/sample_submission.csv`

## Classes

- `fresh_apple`
- `fresh_banana`
- `fresh_orange`
- `rotten_apple`
- `rotten_banana`
- `rotten_orange`

## Evaluation Note

The label provenance of `sample_submission.csv` has not been independently confirmed. Visual inspection found apparent mismatches between some CSV labels and the corresponding images. Do not treat comparisons against this file as authoritative test performance until the labels are verified.
